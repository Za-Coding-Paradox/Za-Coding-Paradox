### `— About —`

<br/>

I am a systems-focused developer and first-year Computer Science undergraduate based in Faisalabad, Pakistan.
My work spans **custom memory allocators**, **AI language model infrastructure**,
and **algorithm visualisation engines** — built from first principles,
with a deep focus on what happens below the abstraction layer.

In my first semester, I earned a position on the **Dean's List**
and placed **5th at Code Clash** — FCAPS's university-wide competitive programming competition —
competing against students two and three years ahead of me.

I currently work at the intersection of **low-level systems engineering**
and **AI runtime architecture**, building tools that don't just work, but work *efficiently*.
